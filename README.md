# Фрактальная мастерская

Учебный командный проект на Python: рекурсивное построение девяти фракталов с помощью `turtle`.

## Структура
- `main.py` — меню и интеграция (роль 4)
- `fractals/basic.py` — дерево и ветка (роль 1)
- `fractals/koch.py` — кривые Коха и Минковского (роль 2)
- `fractals/complex.py` — ледяные фракталы, Леви и дракон (роль 3)

## Запуск
`python main.py`

Рабочая ветка команды — `develop`, готовые изменения объединяются в `main`.

На первом этапе функции являются заглушками и будут реализованы участниками команды.
